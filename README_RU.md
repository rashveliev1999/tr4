# TrimUI Companion NX REDUX — версия 0.4.0

Настольный помощник Windows для управления библиотекой TrimUI Smart Pro с прошивкой NX REDUX. Приложение неофициальное и не связано с разработчиками NX REDUX.

## Что нового в 0.4.0

- Переработанный тёмный интерфейс в стиле NX REDUX: плавный сдвиг страниц, аккуратные карточки, состояния наведения и индикатор фоновых задач.
- Фоновое сканирование microSD, однократная индексация каталогов изображений и SHA-256-проверка дубликатов — медленные операции не выполняются в потоке интерфейса.
- Библиотека сгруппирована по системам; группы сворачиваются, результаты ограничены порциями, есть поиск, фильтр игр без скриншотов и экспорт CSV.
- Редактор игры открывается двойным щелчком: показывает установленный ресурс или `NO IMAGE`, сохраняет выбранную картинку в PNG с правильным именем ROM.
- Поддерживаются типы ресурсов NX REDUX: Screenshot, 3D Box art, 2D Box art, Wheel и Mix.
- Управление логотипом консоли (`Roms/<Система>/.media/logo.png`), фоном системы (`Roms/<Система>/.media/bg.png`) и общим фоном меню (`bg.png` в корне карты).
- Резервное копирование данных NX REDUX на компьютер, с прогрессом и манифестом.
- Диагностика структуры карты, папок систем, тегов `(TAG)` и покрытия обложками.
- Необязательное SFTP-подключение по Wi-Fi, просмотр удалённых папок и передача ресурсов на консоль. Неизвестный SSH-ключ требует явного подтверждения.
- Добавлены модульные тесты для сканирования, путей обложек и обработки папок с multi-disc играми.

## Пути ресурсов NX REDUX

Для каждого игрового файла приложение использует папку `.media` рядом с этим ROM. Для игры в подпапке ресурсы находятся в `.media` той подпапки. Основные стандартные пути:

| Ресурс | Путь |
|---|---|
| Скриншот игры | `.media/screenshot/<ИмяИгры>.png` |
| 3D-обложка | `.media/boxart/<ИмяИгры>.png` |
| 2D-обложка | `.media/boxart2d/<ИмяИгры>.png` |
| Логотип игры (Wheel) | `.media/wheel/<ИмяИгры>.png` |
| Mix | `.media/mix/<ИмяИгры>.png` |
| Логотип системы | `Roms/<Система>/.media/logo.png` |
| Фон системы | `Roms/<Система>/.media/bg.png` |
| Общий фон меню | `bg.png` в корне microSD |

У NX REDUX нет универсальной папки `Themes`, куда можно безопасно копировать произвольные темы. Цвета и макеты меню настраиваются на консоли в `Settings → Appearance / Layouts`; Companion управляет изображениями, для которых официально предусмотрены файловые пути.

Имена системных папок с тегами в скобках, например `Sony PlayStation (PSX)`, полезны для Artwork Manager/ScreenScraper. Само приложение не переименовывает эти папки автоматически.

## Безопасность

- Сканирование и диагностика только читают карту.
- Программа не меняет файлы внутри `.system/`, не прошивает консоль, не удаляет ROM и не оптимизирует/перезаписывает все изображения автоматически.
- При замене конкретного ресурса приложение сначала спрашивает подтверждение. Старый файл с тем же названием удаляется только после успешной записи нового PNG и только в каталоге этого ресурса.
- Backup создаётся на компьютере и не изменяет исходные данные. `.userdata/` содержит пользовательские данные и настройки; такую копию прежде всего следует восстанавливать на той же карте/модели.
- В SFTP неизвестный ключ устройства нельзя принять автоматически: приложение показывает отпечаток и спрашивает подтверждение. Включай SSH/SFTP только в доверенной сети и выключай после передачи файлов.
- Карты microSD NX REDUX собраны под конкретную модель TrimUI. Для переноса прогресса между устройствами следуй официальной инструкции Device Sync, не переставляй карту наугад.

## Установка / запуск из исходников

Требуется Python 3.10+ и Windows.

```bat
python -m pip install --upgrade -r requirements.txt
python trimui_companion.py
```

Или запусти `run.bat`.

## Сборка EXE на Windows

Запусти `build_exe.bat`. Готовый файл будет в `dist\TrimUICompanionNX.exe`.

Также можно загрузить содержимое ZIP в корень GitHub-репозитория. Папка `.github/workflows/build-windows.yml` должна лежать в корне. GitHub Actions сначала запустит тесты, затем соберёт Windows EXE и загрузит EXE вместе с README в артефакт `TrimUICompanionNX-Windows`. Скачанный в Actions ZIP сразу содержит EXE и README (без вложенного архива).

## Проверка тестов

```bat
python -m unittest discover -s tests -v
```
